# ファイル一覧

左右2つのパネルにフォルダーを表示し、キーボードでコピー・移動・削除などを行う。アーカイブ（ZIP・LZH・7Z など）の中も通常のフォルダーと同じように開ける。
画面下部にはファンクションキーの表示、ステータス行、操作ログを並べる。コピーなどの実行中は、ファイル一覧とステータス行の間に進行欄が出る。

## 画面

- **パネル**: 左右に1つずつ。操作の対象は操作中のパネルで、← / → や Tab で切り替える。見出しには今のフォルダーと並び順（例 `[名前▲]`）、絞り込み中は検索語（例 `[vgm]`）を表示する。
- **ファイル名**: 収まらない長い名前は、名前の本体だけを `…` で省略し、拡張子は残す（例 `とても長いファイル名….psd`）。省略は表示だけで、実際の名前は変わらない。
- **空き容量**: パネル下部に、表示中のフォルダーがあるドライブの空き容量を表示する。アーカイブの中では、そのアーカイブが置かれたドライブの値。取得できないドライブは `-` と表示する。
- **ファンクションキー**: F1〜F12 の割り当てを表示する。クリックしてもキーと同じ操作になる。
- **進行欄**: コピー・移動・削除・展開などの実行中だけ表示する（[ファイル操作の進行・中止・順番待ち](#ファイル操作の進行中止順番待ち)）。
- **ログ**: コピー・移動・削除した各ファイルのフルパスと結果を1行ずつ表示する。1件も成功しなかったときも、件数のまとめを出す。

## 操作

| 操作 | キー | 命令 |
| :--- | :--- | :--- |
| 操作一覧の表示 | F1 | &help; |
| カーソル移動 | ↑ / ↓、PageUp / PageDown、Home / End | |
| 左右のパネルを切り替え | ← / →、Tab | |
| フォルダー・アーカイブを開く／ファイルを拡張子の設定で開く | Enter | &extexec; |
| Shift 用の拡張子設定で開く／フォルダーをエクスプローラーで開く | Shift+Enter | &extexecwin; |
| 親フォルダーへ（アーカイブの中から外へも戻る） | BackSpace | |
| マークを付ける／外す | Space / F2 | &mark; |
| 表示中の全項目をマーク | A | &markall; |
| マークをすべて外す | Shift+A | &markclear; |
| マークした項目からアーカイブを作る | Ctrl+A | &archive; |
| 名前で絞り込み | I | &incrimentalsearch; |
| 反対側のパネルへコピー（C は確認あり） | C / Shift+C / F5 | &filecopycheck; / &filecopy; |
| 反対側のパネルへ移動（M は確認あり） | M / Shift+M / F6 | &filemovecheck; / &filemove; |
| 削除（ごみ箱へ。アーカイブの中では項目を削除） | D / Delete / F8 | &filedelete; |
| 実行中のコピー・移動・削除などを中止（確認あり） | Esc | &opcancel; |
| フォルダーを作る | K / F7 | &mkdir; |
| 名前・属性・更新日時の変更 | R / F4 | &filerename; |
| ビューアで開く | F3 | &view; |
| テキストビューア／HEX ビューア | V / Shift+V | &textviewer; / &hexviewer; |
| 画像ビューア | G | &graphicviewer; |
| パスを入力して移動 | J / \ | &chdir; |
| 登録したパスへジャンプ | Shift+J / F10 | &jumplist; |
| ドライブの選択 | L | &drive; |
| 反対側のパネルを同じフォルダーにする | - | &samepath; |
| 並び順の変更 | S / F9 | &sort; |
| 再読み込み | F11 / Ctrl+R | &refresh; |
| 終了 | F12 / Ctrl+Q | &exit; |

- 命令のあるキーは `mf.ini` の `[keys.file]` セクションで変更できる。ファンクションキーの表示名は `%fn01`〜`%fn12`。
- 登録したパスへのジャンプは [ジャンプリスト](jump-list.md) を参照。
- ほかのアプリでファイルを保存・作成・削除・名前変更すると、一覧に自動で反映する。選択とマークはそのまま。アーカイブの中は自動では更新しない（F11 で再読み込み）。
- ファイル名は数字の部分を数の大きさで並べる。たとえば `track2.vgm` は `track10.vgm` より先になる。
- ドライブを選ぶと、パネルごとに移動前の場所と選択位置を覚えておき、同じドライブに戻ったときに元の場所へ戻る。
- Shift+Enter でフォルダーを開いても、パネルの場所は変わらない。`..` では実際の親フォルダーを開く。アーカイブの中のフォルダーはエクスプローラーでは開けない。

## マークと絞り込み

- A は表示中の全ファイル・フォルダーをマークする（`..` は含まない）。絞り込み中は表示中の項目だけを追加でマークする。
- Shift+A は、絞り込みで隠れている項目も含めて、操作中のパネルのマークをすべて外す。
- I を押すと小さな入力欄が開き、文字を入力するたびに一覧を絞り込む。大文字と小文字は区別しない。Enter で絞り込みを決め、Esc で前の絞り込みと選択に戻す。空欄にすると全件を表示する。
- 絞り込んでもマークは残る。別のフォルダーへ移ると絞り込みは解除される。

## ファイル操作の進行・中止・順番待ち

コピー・移動・削除・展開・アーカイブへの追加などの実行中は、ファイル一覧とステータス行の間に進行欄を出す。

```
Copying 1/2  D:\Photos → E:\Backup                                  Esc:Cancel
1 / 3,400 files  52.0 MByte / 106 GByte  85.3 MByte/s  Elapsed 0:12  Left 20:41
▶ D:\Photos\02_Feb\IMG_0120.CR3                       32.0 MByte ■■■■■□□□  63%
  D:\Photos\02_Feb\IMG_0121.CR3
  D:\Photos\02_Feb\IMG_0122.CR3  … 3,395 more
Waiting 2/2  Move  C:\Work\Export → E:\Backup\Export (14 items)
```

- 1行目: 操作の種類と番号（`Copying`・`Moving`・`Deleting`・`Extracting` など）、操作元 → 操作先、中止キー。中止を受け付けると `Cancelling: Copy` のように変わる。
- 2行目: 処理済みと全体の件数・量、速度、経過時間（Elapsed）、残りの見込み（Left）。始める前に対象を数え、その間は `Counting n files` と出す。
- 3行目: 処理中のファイルのフルパス、大きさ、そのファイルの進み具合。
- その下: 次に処理するファイル（3件まで）と残りの件数（`… n more`）、順番待ちの作業（`Waiting`、2件まで）。

Esc を押して確認で「はい」を選ぶと中止する。

- コピーと別ドライブへの移動は、ファイルの途中でも止まる。書きかけのファイルは消し、コピー先・移動先にもともとあったファイルは変えない。移動は置き終えてから元を消すので、どこで止めてもファイルは失われない。
- 終わった分はそのまま残る。処理し終えた項目のマークは外し、残りはマークしたままにする。ステータス行とログに処理済み・エラー・未処理の件数を出す。
- 削除（ごみ箱）は項目と項目の間で止まる。フォルダーは中身ごと1回でごみ箱へ送るので、その途中では止まらない。
- アーカイブへの追加・アーカイブの中の削除は、中止すると何も変わらない。

実行中に別のコピー・移動・削除などを始めると、順番待ちにして、前の操作が終わってから実行する。中止は実行中の操作だけに効き、待ちの操作はそのあと順に実行する。待ちの操作を個別に取り消すことはできない。操作中・待ちの間はアプリを終了できない。

## キーから外部アプリを起動する

`[keys.file]` セクションのキーには、`&...;` の命令の代わりに実行ファイルと引数を書ける。ファンクションキーにも割り当てられ、画面下部のクリックでも起動する。

```ini
>KEY_E -s-- C:\Tools\viewer.exe %markfiles;
>KEY_F3 -s-- "C:\Program Files\Editor\editor.exe" --new-window %markfiles;
```

- `%markfiles` は、操作中のパネルでマークしたファイルのフルパスに置き換わり、1件ずつ別の引数として渡される。絞り込みで隠れているマークも含む。フォルダーと、マークしていないカーソル位置のファイルは含まない。
- マークがなくても起動し、`%markfiles` の部分は0件になる。`--new-window` のような固定の引数は残る。起動してもマークはそのまま。
- 空白を含む実行ファイルや引数は `"` で囲む。環境変数は起動時に展開する。相対パス（例 `.\tools\editor.exe`）は `mf.exe` のフォルダーが基準で、名前だけなら Windows の検索パスから探す。
- 作業フォルダーは操作中のパネルのフォルダー。アーカイブの中では、アーカイブが置かれたフォルダーになる。アーカイブの中のファイルは一時フォルダーへ取り出したものを渡すので、外部アプリで保存してもアーカイブには反映されない。
- 行末の `;` は行の終わりの印。空白に続く `#` はコメント。`"` の中の `#` と `;` はそのままの文字になる。引数の中の `"` は `\"`、`"` の直前の `\` は `\\` と書く。
- 起動できないとき、マークしたファイルが見つからないとき、取り出しに失敗したときは、ステータス行とログに表示する。

## ログ

ログ欄のすぐ上の行の右端にある `[Lv2:標準]` をクリックすると、表示するログの細かさを切り替える。左クリックで1段上げ、右クリックで1段下げる（端では反対側へ回る）。

| レベル | 表示するログ |
| :--- | :--- |
| Lv0 最小 | エラー・警告のみ |
| Lv1 要所 | 主要な操作と結果のまとめ |
| Lv2 標準 | 標準（フォルダー移動を含む） |
| Lv3 詳細 | すべて |

## 設定

`mf.ini` で設定する。変更はアプリの再起動で反映される。

```ini
# ログ欄の行数 1〜20（既定 6）
%logRows   6
# ファイル一覧の行数 5〜100。0 は固定の高さ（既定 0）
%fileRows  0
# 終了時に左右のフォルダー・並び順・ログのレベルを保存する 1 / しない 0（既定 1）
%saveState 1
```

- **%fileRows**: 0 のときウィンドウの高さは固定（832）で、`%logRows` を増やすと一覧の行数が減る。行数を指定すると、一覧とログがそれぞれその行数になるようにウィンドウの高さを決める。
  - 画面に収まらない行数は収まる行数まで減らし、最小の高さ（640）を下回る行数は増やす。下端が画面からはみ出すときはウィンドウを上へ寄せる。
  - サウンドビューアは、曲の一覧の行数が標準の高さのときと同じなら、そのままの高さで表示する。行数が減るときだけ標準の高さに戻し、閉じると元に戻す。ほかのビューアは指定の高さのまま表示する。
  - 例: `%logRows 6`・`%fontSize 14` で `%fileRows 27` にすると、高さ 829 で一覧の下に半端な隙間ができない。
- **%saveState**: 0 にすると終了時に `mf.ini` を書き換えず、次回も `mf.ini` に書かれたフォルダーと並び順で始まる。`mf.ini` がないときも作らない。
- 画面の各色は `%theme_...` の行で変更できる。

## 起動時のウィンドウの位置

ウィンドウが画面（タスクバーを除く範囲）からはみ出すときだけ、そのモニターの中央に置く。収まっていれば Windows が決めた位置のまま。大きさは変えないので、ウィンドウが画面より大きいときは中央に置いても全体は収まらない。
