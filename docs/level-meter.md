# レベルメーター算出仕様

MirrorFlux のサウンドビューアおよびサウンドバーに表示されるチャンネル別レベルメーターの算出ロジックと、音源別の計算式仕様をまとめる。

---

## 1. UI描画・セグメント化仕様（`MusicMeterDisplay`）

各音源・ドライバが出力する正規化レベル値 $\text{Level} \in [0.0, 1.0]$（`MusicChannelSnapshot.Level`）をもとに、画面上のドット（セグメントマス）点灯数へと変換する。

### 1.1 セグメント（マス）の分割と高さ
表示領域のピクセル高さおよび表示スケール（サウンドビューアは `DisplayScale = 1.5`、サウンドバーは `1.0`）から全セグメント数 $S$ を決定する。

- 1セグメント（マス）の描画高さ:
  $$\text{heightPixels} = \max(2, \, \text{round}(2 \times \text{scale}))$$
- 1セグメントのステップ幅（隙間含む）:
  $$\text{stepPixels} = \max(3, \, \text{round}(3 \times \text{scale}))$$
- 有効描画高さ $\text{PlotHeight}$ 内の総セグメント数 $S$:
  $$S = \max\left(1, \, \left\lfloor \frac{\text{PlotHeight}}{\text{stepPixels} \times \text{pixelY}} \right\rfloor - \text{HiddenTopSegments}\right)$$

### 1.2 点灯セグメント数の計算
下から点灯するセグメント数 $\text{lit}$ は、$\text{Level}$ に総セグメント数 $S$ を掛けた四捨五入値となる:
$$\text{lit} = \text{round}(\text{clamp}(\text{Level}, 0, 1) \times S)$$
- $0 \le \text{segment} < \text{lit}$: 点灯色（`MeterLit`）
- $\text{lit} \le \text{segment} < S$: 消灯色（`MeterOff`）
- チャンネル消音（ミュート）時: 暗い境界色（`KeyboardInactiveWhiteBorder`）

### 1.3 ピークホールドと減衰（ディケイ）
- **ピークホールド**:
  $$\text{peakSegment} = \text{clamp}(\text{round}(\text{Peak} \times S), \, 1, \, S)$$
  - 最大レベル到達時に 16 フレーム（約270ms）保持。
  - ホールド期間終了後、毎フレーム $-0.025$ ずつリニアに下降。
- **残光・減衰挙動**:
  - `UsesEnvelopeTiming == true` の音源（FMなど自前で時間エンベロープを追従する音源）:
    毎フレームの計算値をダイレクトに適用（表示側の平滑化をバイパス）。
  - その他の音源（PSG、PCM、GME等）:
    上昇時は即時追従、下降時は毎フレーム $\text{Level} \times 0.96$（指数減衰）により滑らかな残光を描画。

## 2. 音源別の $\text{Level}$ 算出式

### 2.1 FM音源（OPM: YM2151 / OPN系: YM2203, YM2608, YM2610, YM2612）
FM音源は単一ボリュームレジスタではなく、**キャリア（最終出力）オペレーターの Total Level（TL）と、AR/RR によるエンベロープ進行**からリアルタイムに合成・算出される。

1. **アルゴリズム（ALG 0〜7）に応じたキャリアオペレーターの特定**:
   - ALG 0..3: オペレーター4（スロット4）のみ（キャリアマスク `0b1000`）
   - ALG 4: オペレーター2, 4（`0b1010`）
   - ALG 5, 6: オペレーター2, 3, 4（`0b1110`）
   - ALG 7: オペレーター1, 2, 3, 4 すべて（`0b1111`）
2. **キャリア減衰レベル（Total Level: TL）**:
   各キャリアスロットの TL（$0 \sim 127$、1ステップあたり $0.75\text{dB}$ 減衰）から音量倍率を算出:
   $$\text{carrierLevel} = 10^{-\frac{\text{TL} \times 0.75}{20}}$$
   複数キャリアが存在する場合は、最も音量の大きい（レベルが高い）キャリアの値を採用。
3. **アタック / リリース エンベロープ時間シミュレーション**:
   - アタックレート AR（$0 \sim 31$）からアタック時間（秒）を算出:
     $$\text{AtkSec} = \text{clamp}\left(12.0 \times 2^{-\frac{\text{AR}}{3.0}}, \, 0.015, \, 12.0\right)$$
   - リリースレート RR（$0 \sim 15$）からリリース時間（秒）を算出:
     $$\text{RelSec} = \text{clamp}\left(12.0 \times 2^{-\frac{\text{RR}}{2.0}}, \, 0.06, \, 12.0\right)$$
   - 前フレームからの経過時間 $\Delta t$（秒）に応じて内部エンベロープ変数 $\text{Env}$ を進行:
     - KeyOn中: $\text{Env} = \min\left(1.0, \, \text{Env} + \frac{\Delta t}{\text{AtkSec}}\right)$
     - KeyOff中: $\text{Env} = \max\left(0.0, \, \text{Env} - \frac{\Delta t}{\text{RelSec}}\right)$
     - キーオン再発音（リトリガー）時: $\text{Env} = 0$ にリセット
4. **最終メーターレベル**:
   $$\text{Level} = (\text{再生中} \land \text{PAN} \neq 0) \,?\, (\text{Env} \times \text{carrierLevel}) : 0$$

---

### 2.2 OPL系FM音源（YM2413 / YMF262 / YM3812 / YM3526 / VRC7）
キャリアスロットの音量レジスタ値から直接正規化される。
- **YM2413 / VRC7 (OPLL)**:
  - 音量レジスタ（$0 \sim 15$、小さいほど大音量）
  - $\text{volume} = 15 - (\text{reg} \mathbin{\text{AND}} 15)$
  - $\text{Level} = \frac{\text{volume}}{15.0}$
- **YMF262 (OPL3) / YM3812 / YM3526 (OPL2)**:
  - キャリア減衰レジスタ（$0 \sim 63$）
  - $\text{volume} = 63 - (\text{reg} \mathbin{\text{AND}} 63)$（4OP時はペアの2つのキャリアのうち大きい方）
  - $\text{Level} = \frac{\text{volume}}{63.0}$
- **リズムチャンネル（BD / SD / HH / CYM / TOM）**:
  - ドラム発音ビットが有効なとき、対応する打楽器音量（OPLL: /15、OPL: /63）を出力。

---

### 2.3 PSG / SSG音源（AY-3-8910 / YM2149 / YM2203・2608・2610内蔵SSG）
音量レジスタ（$0 \sim 15$）をもとに、$1.5\text{dB}$ ステップの対数減衰カーブをエミュレートして算出される。
- **固定音量モード**:
  $$\text{Level} = 10^{\frac{(\text{volume} - 15) \times 1.5}{20}}$$
  （volume=15で $1.0$、volume=14で約 $0.84$、volume=0で約 $0.07$）
- **ハードウェアエンベロープモード**（音量レジスタの bit 4 が 1）:
  $$\text{Level} = 0.6 \quad (\text{固定値})$$
  ※トーン・ノイズともにOFFの無音時は $\text{Level} = 0$。

---

### 2.4 DCSG音源（SN76489）
各チャンネルの減衰値レジスタ $\text{att}$（$0 \sim 15$、15は完全消音）から $2\text{dB}$ ステップの対数減衰で算出される。
- $\text{att} = 15$: $\text{Level} = 0$
- $\text{att} < 15$:
  $$\text{Level} = 10^{-\frac{\text{att} \times 2.0}{20}} = 10^{-\frac{\text{att}}{10.0}}$$
  （att=0で $1.0$、att=1で約 $0.79$、att=14で約 $0.04$）

---

### 2.5 波形メモリ音源
- **SCC / SCC+（K051649 / K052539）**:
  音量レジスタ（$0 \sim 15$）から線形正規化:
  $$\text{Level} = \frac{\text{volume}}{15.0}$$
- **PCエンジン HuC6280**:
  チャンネル主音量（$0 \sim 31$）と左右出力レベル（$0 \sim 15$）を掛け合わせた総合出力から正規化:
  $$\text{Level} = \max(\text{LeftLevel}, \, \text{RightLevel})$$

---

### 2.6 リズム・ADPCM・PCM各種音源 (VGM)
- **YM2608 / YM2610（リズム6音・ADPCM-B）**:
  打楽器トリガーおよび音量レジスタ（$0 \sim 63$）から $\frac{\text{volume}}{63.0}$
- **OKIM6258（X68000 ADPCM）**:
  転送されたADPCMデータ（4bitニブル）の上位/下位絶対値から動的振幅を算出:
  $$\text{activity} = \frac{\max(\text{val} \gg 4, \, \text{val} \mathbin{\text{AND}} 7)}{7.0}$$
  $$\text{Level} = \max(0.08, \, \text{activity})$$
- **YM2612 DAC（メガドライブ等のPCM）**:
  出力バイト値（$0 \sim 255$）の中心（128）からの絶対偏差:
  $$\text{Level} = \frac{|\text{value} - 128|}{127.0}$$
- **C140 / C352（ナムコPCM）**:
  減衰レジスタから対数減衰（C140は24dBレンジ、C352は36dBレンジ）:
  $$\text{Level} = 10^{\frac{-24.0 \times \text{att} / 64}{20.0}} \times \max(\text{left}, \, \text{right})$$
- **RF5C68 / RF5C164（メガCD等）**:
  音量（$0 \sim 255$）および左右パン値から $\max(\text{left}, \, \text{right})$
- **ES5503 / ES5505 / ES5506**:
  各ボイスの音量レジスタ（$0 \sim 255$）から $\frac{\text{volume}}{255.0}$
- **SegaPCM（16ch）**:
  ゲインレジスタ（$0 \sim 127$）および左右パン音量から $\frac{\max(\text{left}, \, \text{right})}{127.0}$

---

### 2.7 MDX（X68000 MXDRV）
- **FM部（YM2151）**:
  MXDRVの内部音量パラメータ（$0 \sim 15$ または $0 \sim 127$）から減衰値 $\text{att}$（$0 \sim 127$、小さいほど大音量）を取得し線形変換:
  $$\text{Level} = \text{clamp}\left(\frac{127 - \text{att}}{127.0}, \, 0, \, 1\right) \quad (\text{KeyOn中のみ、KeyOff時は } 0)$$
- **PCM8部**:
  各ボイスの16bit PCM実波形とボイスゲインから、フレーム内の最大実効ピーク（絶対値振幅）をダイレクトに検出:
  $$\text{Level} = \frac{|\text{sample}|_{\max}}{32768.0}$$

---

### 2.8 GME音源（NSF, SPC, GBS, HES, AY, KSS 等）
ドライバ内部レジスタではなく、エミュレータがチャンネル個別に分離出力した**実波形のRMS（実効値）**から算出される。
$$\text{RMS} = \sqrt{\frac{1}{N} \sum_{i=1}^N (x_i - \text{平均値})^2}$$
$$\text{Level} = \text{clamp}(\text{RMS} \times 6.0, \, 0, \, 1)$$

---

### 2.9 通常オーディオファイル（WAV, MP3, FLAC, OGG, M4A）
個別チャンネルメーターではなく、出力波形に対する 8192 サンプルの Hann 窓 FFT から 24 バンド（10 Hz〜22,050 Hz）の対数スペクトラムアナライザー（`AudioSpectrumAnalyzer`）として描画される。

## 3. 音源別・音量設定レジスタ仕様一覧

各音源のハードウェアレジスタに対してソフトウェア（シーケンサー・ドライバ）が設定する音量パラメータのアドレス、ビット配置、数値の意味（減衰／リニア等）、およびパン設定仕様をまとめる。

### 3.1 FM音源（OPM: YM2151 / OPN系: YM2203, YM2608, YM2610, YM2612）
FM音源はチャンネル全体の単一ボリュームレジスタを持たず、**4つのオペレーター（スロット）それぞれの Total Level（TL）レジスタ**によって音量・音色が決定される。
最終的な出力音量は、アルゴリズム（ALG）によって「キャリア（外部へ出力されるオペレータ）」に指定されたスロットの TL 値によって制御される。

#### 1. Total Level (TL) レジスタ
- **YM2151 (OPM)**:
  - アドレス: `0x60 + (slot * 8) + ch`
    - `slot`: 0 (M1), 1 (M2), 2 (C1), 3 (C2)
    - `ch`: 0 〜 7 (8チャンネル)
- **YM2203 / YM2608 / YM2610 / YM2612 (OPN系)**:
  - アドレス: `0x40 + (slot_offset) + ch_offset`
    - ポート0 (CH 1〜3): `ch_offset` = 0, 1, 2
    - ポート1 (CH 4〜6): `ch_offset` = 0, 1, 2 (YM2608/2610/2612)
    - `slot_offset`: Slot 1 = `0x00`, Slot 3 = `0x04`, Slot 2 = `0x08`, Slot 4 = `0x0C` (YAMAHA配置順)
- **ビット配置**: `D6..D0`（7bit、値: $0 \sim 127$、最上位ビット D7 は未使用）
- **特性**: **対数減衰値（Attenuation）**
  - `0`: 減衰なし（最大音量 $0\text{ dB}$）
  - `127`: 最大減衰（約 $-95.25\text{ dB}$、実質消音）
  - $1\text{ step} = 0.75\text{ dB}$ 減衰
  - 倍率計算式: $\text{gain} = 10^{-\frac{\text{TL} \times 0.75}{20}}$

#### 2. アルゴリズム（ALG）とパン（PAN）レジスタ
- **YM2151 (OPM)**:
  - アドレス: `0x20 + ch`
  - `D2..D0`: ALG（$0 \sim 7$、キャリアスロットを決定）
  - `D5..D3`: フィードバック率（FL: $0 \sim 7$）
  - `D7..D6`: PAN（D7=Right, D6=Left。00: 消音, 01: L, 10: R, 11: Center）
- **OPN系（YM2608 / YM2610 / YM2612）**:
  - アドレス: `0xB0 + ch_offset`（ALG / Feedback）
    - `D2..D0`: ALG（$0 \sim 7$）
    - `D5..D3`: フィードバック率（$0 \sim 7$）
  - アドレス: `0xB4 + ch_offset`（PAN / LFO PM）
    - `D7..D6`: PAN（**D7=Left, D6=Right**。※OPMとL/Rビットが逆順）
    - `D5..D4`: LFO AMS（振幅変調感度）
    - `D2..D0`: LFO PMS（位相変調感度）
  - ※YM2203 はモノラル出力のため PAN レジスタなし。

#### 3. エンベロープパラメータ（AR / DR / SR / RR / SL）
- **Attack Rate (AR)**:
  - OPM: `0x80 + slot*8 + ch` / OPN: `0x50 + slot*4 + ch`
  - `D4..D0`: AR（5bit、$0 \sim 31$、31=最速アタック）
- **Release Rate (RR)**:
  - OPM: `0xE0 + slot*8 + ch` / OPN: `0x80 + slot*4 + ch`
  - `D3..D0`: RR（4bit、$0 \sim 15$、15=最速リリース）
- **Decay Rate (DR / D1R)**:
  - OPM: `0xA0 + slot*8 + ch` / OPN: `0x60 + slot*4 + ch`（5bit, $0 \sim 31$）
- **Sustain Rate (SR / D2R)**:
  - OPM: `0xC0 + slot*8 + ch` / OPN: `0x70 + slot*4 + ch`（5bit, $0 \sim 31$）
- **Sustain Level (SL)**:
  - OPM: `0xE0 + slot*8 + ch` / OPN: `0x80 + slot*4 + ch` の上位ビット `D7..D4`（4bit, $0 \sim 15$、1ステップ $-3\text{ dB}$）

---

### 3.2 OPL系 FM音源（YM2413 / YM3812 / YMF262 等）

#### 1. YM2413 / VRC7 (OPLL)
- **チャンネル音量**:
  - アドレス: `0x30 + ch`（ch: $0 \sim 8$）
  - `D3..D0`: 音量・減衰値（4bit、$0 \sim 15$）
  - **特性**: **減衰値（0=最大音量、15=最小音量/消音、1ステップ $3\text{ dB}$）**
  - `D7..D4`: 音色インストゥルメント番号（0=オリジナル音色、1〜15=内蔵ROM音色）
- **リズムモード時の音量**:
  - アドレス `0x0E`: `D5`=リズムモード有効化、`D4..D0`=各打楽器トリガー
  - アドレス `0x36`: ベースドラム（BD）音量（`D3..D0`）
  - アドレス `0x37`: ハイハット（HH: `D3..D0`）／スネアドラム（SD: `D7..D4`）
  - アドレス `0x38`: トムトム（TOM: `D7..D4`）／トップシンバル（CYM: `D3..D0`）

#### 2. YM3812 (OPL2) / YMF262 (OPL3)
- **Total Level (TL) レジスタ**:
  - アドレス: `0x40 + slot_offset`
  - `D5..D0`: TL（6bit、$0 \sim 63$）
  - **特性**: **対数減衰値（0=最大音量 $0\text{ dB}$、63=最小音量 $-47.25\text{ dB}$、1ステップ $0.75\text{ dB}$）**
  - `D7..D6`: KSL（Key Scale Level: 0=なし、1=1.5dB/oct、2=3dB/oct、3=6dB/oct）
- **OPL3 パン & 接続設定**:
  - アドレス: `0xC0 + ch`
  - `D5`: Left 出力有効化
  - `D4`: Right 出力有効化
  - `D0`: 接続方式（0: FM変調 2OP直列、1: 加算合成 2OP並列＝両オペレータがキャリア）

---

### 3.3 PSG / SSG音源（AY-3-8910 / YM2149 / YM2203・2608・2610内蔵SSG）

- **チャンネル音量レジスタ**:
  - アドレス: `0x08` (CH A), `0x09` (CH B), `0x0A` (CH C)
  - ビット構成:
    - `D3..D0`: 固定音量値（4bit、$0 \sim 15$）
    - `D4`: ハードウェアエンベロープ有効化フラグ（**Mビット**）
  - **特性**:
    - `D4 = 0`（固定音量）: $0 = \text{消音}$、$15 = \text{最大音量}$。各ステップ約 $1.5\text{ dB}$（AY-3-8910）〜 $2.0\text{ dB}$ の対数特性。
    - `D4 = 1`（HWエンベロープ）: D3..D0 は無視され、エンベロープジェネレーター（周期レジスタ `0x0B/0x0C`、波形レジスタ `0x0D`）の出力に従って振幅が時間変化。
- **トーン／ノイズ出力スイッチ（ミキサー）**:
  - アドレス: `0x07`
  - `D2..D0`: トーン有効化（0=有効, 1=無効。CH A/B/C）
  - `D5..D3`: ノイズ有効化（0=有効, 1=無効。CH A/B/C）

---

### 3.4 DCSG音源（SN76489）

SN76489 はアドレスバスを持たず、8bitのコマンドバイト（ラッチ書き込み）およびデータバイトで直接設定する。

- **減衰値設定コマンド形式**:
  - バイト値: `1 c c 1 a a a a`
    - ビット7: `1`（ラッチコマンド）
    - `c c`（ビット6..5）: チャンネル指定
      - `00`: Tone 1
      - `01`: Tone 2
      - `10`: Tone 3
      - `11`: Noise
    - ビット4: `1`（音量／減衰値レジスタ指定。`0` のときは周期設定）
    - `a a a a`（ビット3..0）: 減衰値 $\text{att}$（4bit、$0 \sim 15$）
- **特性**: **対数減衰値（Attenuation）**
  - `0`: 減衰なし（最大音量 $0\text{ dB}$）
  - `1`〜`14`: 1ステップごとに $2\text{ dB}$ 減衰（14 で $-28\text{ dB}$）
  - `15` (`0x0F`): **完全消音（Mute）**
- **Game Gear ステレオパンレジスタ**（VGMコマンド `0x4F`）:
  - 1バイトで4チャンネルの左右出力を指定:
    - `D7..D4`: Noise, Tone 3, Tone 2, Tone 1 の Left 出力 (1=ON, 0=OFF)
    - `D3..D0`: Noise, Tone 3, Tone 2, Tone 1 の Right 出力 (1=ON, 0=OFF)

---

### 3.5 波形メモリ音源

#### 1. コナミ SCC / SCC+ (K051649 / K052539)
- **音量レジスタ**:
  - SCC: アドレス `0x0A`〜`0x0E`（CH 1〜5）
  - SCC+: アドレス `0x200 + ch`（CH 1〜5）
  - ビット構成: `D3..D0`（4bit、$0 \sim 15$）
  - **特性**: **リニア音量（0=消音、15=最大音量）**
- **チャンネルON/OFF**:
  - レジスタ `0x0F`（ビット0〜4で CH 1〜5 の出力許可。1=ON, 0=OFF）

#### 2. PCエンジン HuC6280
HuC6280 はインデックスレジスタ方式を採用している。
- **チャンネル選択**: レジスタ `0x00` にチャンネル番号（$0 \sim 5$）を書き込み、対象チャンネルを選択。
- **チャンネル主音量 & 制御**: レジスタ `0x04`
  - `D7`: チャンネル有効化（1=ON, 0=OFF）
  - `D6`: DDA（Direct D/A）モード（1=PCM直出力, 0=波形メモリ再生）
  - `D4..D0`: **チャンネルボリューム（5bit、$0 \sim 31$、0=消音、31=最大音量、リニア特性）**
- **チャンネルパン（左右バランス）**: レジスタ `0x05`
  - `D7..D4`: **左出力音量（4bit、$0 \sim 15$）**
  - `D3..D0`: **右出力音量（4bit、$0 \sim 15$）**
- **全体マスターボリューム**: レジスタ `0x01`
  - `D7..D4`: 全体左マスター音量（4bit、$0 \sim 15$）
  - `D3..D0`: 全体右マスター音量（4bit、$0 \sim 15$）

---

### 3.6 リズム・PCM・ADPCM音源

#### 1. YM2608 / YM2610 リズム & ADPCM
- **YM2608 (OPNA) リズム音源 (6音: BD, SD, TOP, HH, TOM, RIM)**:
  - ポート0 レジスタ `0x11`: **リズムトータルボリューム（`D5..D0`: 6bit、$0 \sim 63$、0=消音、63=最大）**
  - ポート0 レジスタ `0x18`〜`0x1D`: **個別楽器音量（`D4..D0`: 5bit、$0 \sim 31$）**
  - ポート0 レジスタ `0x10`: 発音トリガー（D7=キーオン、D5..D0=各楽器ビット）
- **YM2608 (OPNA) ADPCM-B (1ch)**:
  - ポート1 レジスタ `0x0B`: **ADPCMボリューム（`D7..D0`: 8bit、$0 \sim 255$、0=消音、255=最大）**
  - ポート1 レジスタ `0x01`: PAN（D7=Left, D6=Right）
- **YM2610 (OPNB) ADPCM-A (6ch)**:
  - ポート1 レジスタ `0x20`: **ADPCM-A トータルボリューム（`D5..D0`: 6bit、$0 \sim 63$）**
  - ポート1 レジスタ `0x08`〜`0x0D`: **個別チャンネル音量 & パン**
    - `D7..D6`: PAN（D7=Left, D6=Right）
    - `D4..D0`: 音量（5bit、$0 \sim 31$、0=消音、31=最大）

#### 2. OKIM6258 (X68000 ADPCM)
- 音量レジスタは持たず、送信される4bit ADPCMサンプルの振幅そのものが音量となる。
- コントロールレジスタでパン（Left/Right）およびサンプリング周波数（3.9k/7.8k/10.4k/15.6kHz）を切り替える。

#### 3. YM2612 DAC (メガドライブ PCM)
- レジスタ `0x2A`: **8bit DACデータ出力（$0 \sim 255$）**
  - 符号なし8bit PCMデータそのもの（中心値 $128$、振幅は $|v - 128|$）
- レジスタ `0x2B`: DAC有効化（D7: 1=DAC有効・FM CH6消音、0=通常のFM CH6動作）

#### 4. ナムコ C140 / C352
- **C140 (24ボイス)**:
  - 各ボイス先頭レジスタ:
    - `0x00`: ボリューム／パン（`D7..D4`: 左右ゲイン、減衰値 $0 \sim 63$、$-24\text{ dB}$ レンジ）
- **C352 (32ボイス)**:
  - 各ボイスレジスタ:
    - 減衰値レジスタ（$0 \sim 255$、$-36\text{ dB}$ レンジ対数減衰）
    - 4ch出力（Front L/R, Rear L/R）ごとのルーティング

#### 5. リコー RF5C68 / RF5C164 (メガCD等 PCM 8ch)
- レジスタ `0x00`: **エンベロープ音量（8bit、$0 \sim 255$、0=消音、255=最大）**
- レジスタ `0x01`: **パンポット音量**
  - `D7..D4`: Right 出力音量（4bit、$0 \sim 15$）
  - `D3..D0`: Left 出力音量（4bit、$0 \sim 15$）
- レジスタ `0x07`: チャンネル有効化フラグ（8bit、各ビット 0=再生中, 1=停止）

#### 6. Ensoniq ES5503 / ES5505 / ES5506 (DOC)
- **ES5503 (32ボイス)**:
  - アドレス `0x40 + voice`: **ボイス音量（8bit、$0 \sim 255$、0=消音、255=最大）**
  - アドレス `0xA0 + voice`: コントロール（`D7..D4`: 出力チャンネルルーティング・パン、`D0`: 発音停止フラグ）
- **ES5505 / ES5506**:
  - 各ボイスの左右ボリュームレジスタ（12bit または 16bit リニア音量）

#### 7. セガ SegaPCM (16ch)
- アドレス `ch * 8 + 0x02`: **Left ゲイン（7bit、$0 \sim 127$、0=消音、127=最大）**
- アドレス `ch * 8 + 0x03`: **Right ゲイン（7bit、$0 \sim 127$、0=消音、127=最大）**
- アドレス `ch * 8 + 0x86`: 制御フラグ（`D0`: 0=発音中, 1=停止）

### 3.7 任天堂系 (FC / GB)

#### 1. ファミコン NES APU (2A03)
- **パルス波 1 / 2 (矩形波)**: アドレス `$4000` / `$4004`
  - `D3..D0`: **ボリューム値（4bit、$0 \sim 15$、0=消音、15=最大）**
  - `D4`: 固定音量フラグ（1=D3..D0固定音量、0=内部ディケイエンベロープ使用）
  - `D7..D6`: デューティ比（12.5%, 25%, 50%, 75%）
- **三角波**: アドレス `$4008`
  - 音量レジスタなし（常にフル振幅 4bit 固定波形を出力、リニアカウンタでON/OFF制御）
- **ノイズ**: アドレス `$400C`
  - `D3..D0`: **ボリューム値（4bit、$0 \sim 15$）**
  - `D4`: 固定音量フラグ（1=固定音量、0=内部エンベロープ）
- **DPCM**: アドレス `$4011`
  - `D6..D0`: **7bit DAC直接出力値（$0 \sim 127$、初期値 64）**
- **FDS (ディスクシステム音源)**:
  - アドレス `$4080`: `D7`=直接音量モードフラグ、`D5..D0`=ボリューム値（$0 \sim 32$）

#### 2. ゲームボーイ DMG
- **CH1 / CH2 (矩形波)**: レジスタ `NR12 ($FF12)` / `NR22 ($FF17)`
  - `D7..D4`: **初期音量値（4bit、$0 \sim 15$、0=消音、15=最大）**
  - `D3`: エンベロープ増減方向（1=増大、0=減衰）
  - `D2..D0`: エンベロープステップ周期（0=エンベロープ停止）
- **CH3 (波形メモリ)**: レジスタ `NR32 ($FF1C)`
  - `D6..D5`: **出力レベル選択**
    - `00`: 完全消音（Mute）
    - `01`: 100%（無減衰）
    - `10`: 50%（1bit右シフト減衰）
    - `11`: 25%（2bit右シフト減衰）
- **CH4 (ノイズ)**: レジスタ `NR42 ($FF21)`
  - `D7..D4`: **初期音量値（4bit、$0 \sim 15$）**
- **マスター音量 & パン**:
  - `NR50 ($FF24)`: 左右マスターボリューム（`D6..D4`: Left $0 \sim 7$、`D2..D0`: Right $0 \sim 7$）
  - `NR51 ($FF25)`: 各チャンネル（CH 1〜4）の左右ルーティング（8bitマスク）

### 3.8 MDX (X68000 MXDRV) 演奏コマンドと音量パラメータ

MXDRV MML における音量指定は以下の2系統が存在する。

1. **`@v` コマンド（絶対音量）**:
   - 書式: `@v<n>`（$n = 0 \sim 15$、拡張モード時は $0 \sim 127$）
   - **FM部（YM2151）へのマッピング**:
     MXDRV 内部の音量テーブル（対数カーブテーブル）を参照し、音色定義で設定された基本 TL 値に対して減衰値オフセットを加算する。
     $$\text{TL}_{\text{carrier}} = \text{clamp}(\text{BaseTL} + \text{VolumeTable}[\text{volume}], \, 0, \, 127)$$
     これにより、MML 上の音量（値が大きいほど大音量）が OPM の TL（値が小さいほど大音量）へと変換される。
   - **PCM8部へのマッピング**:
     $16\text{bit}$ PCM 出力振幅に対する乗算ゲインとして直接適用される。
2. **`v` コマンド（相対音量）**:
   - 書式: `v<n>`（$n = 0 \sim 15$）
   - ボイス定義の基準音量に対する相対ステップとして機能。
3. **パンポット コマンド**:
   - 書式: `p<n>`（$0$: 消音、$1$: 左、$2$: 右、$3$: 中央）
   - OPM レジスタ `0x20 + ch` の `D7..D6`（PAN）へそのまま反映される。
