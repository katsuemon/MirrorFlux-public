# アーカイブ

ZIP・LZH などのアーカイブを、ファイル一覧の中で通常のフォルダーと同じように開ける。中のファイルを見る・取り出すほか、形式によっては中への追加・削除・フォルダー作成や、新しいアーカイブの作成もできる。7-Zip などを別に入れる必要はない。

## 対応形式

| 形式 | 拡張子 | 閲覧・展開 | 中の編集（追加・削除・フォルダー作成） | 新規作成 |
| :--- | :--- | :---: | :---: | :---: |
| ZIP | .zip | ○ | ○ | ○ |
| 7Z | .7z | ○ | ○ | ○ |
| LZH / LHA | .lzh / .lha | ○ | ○ | ○（.lzh） |
| TAR | .tar | ○ | ○ | ○ |
| RAR | .rar | ○ | — | — |
| GZ・TGZ など | .gz / .tgz ほか | ○ | — | — |

- RAR は分割したもの・ソリッドにも対応する。パスワード付きの RAR は開けない。
- 元のアーカイブを書き換えるのは、中を編集したときだけ。

## 開き方と操作

ファイル一覧でアーカイブにカーソルを合わせて Enter を押すと、中を開く。BackSpace で外へ戻る。中でのコピー・削除・フォルダー作成などは、通常のフォルダーと同じキーで行う（[ファイル一覧](file-list.md)）。

- **取り出す**: 中のファイルやフォルダーを反対側のパネルへコピーする。
- **追加する**: 反対側のパネルからアーカイブの中へコピーする。
- **中のファイルを開く**: Enter やビューアのキーで開くと、一時フォルダーへ取り出したものを表示する。

## 新規作成

ファイルやフォルダーをマークして Ctrl+A（`&archive;`）を押すと、小さな画面で形式・ファイル名・圧縮率を選べる。Enter で作成する。

| 操作 | キー |
| :--- | :--- |
| 項目の移動 | ↑ / ↓ |
| 形式・圧縮率の選択 | ← / → |
| 作成 | Enter |
| 取り消し | Esc |

| 形式 | 圧縮率 | 名前 |
| :--- | :--- | :--- |
| ZIP | 無圧縮・高速・標準・高圧縮（初期は標準） | 日本語名を使える |
| 7Z | 標準のみ | 日本語名を使える |
| LZH | 固定 | 日本語名を使える。絵文字など一部の文字は使えない |
| TAR | 圧縮なし | 日本語名を使える |

- 作成先は同じパネルの今のフォルダー。同じ名前のファイルがあるときは上書きしない。作成後は新しいアーカイブにカーソルが移る。
- フォルダーをマークすると、中身を空のフォルダーも含めてまとめる。
- LZH に使えない文字の名前があるときは、作成を中止する。作成画面にもこの注意を表示する。

## 中の編集

ZIP・7Z・LZH/LHA・TAR は、中へのファイルの追加、削除、フォルダー作成ができる。

- 編集はいったん別のファイルに書いてから元と置き換える。途中で失敗・中止したときや、元のアーカイブが使用中で置き換えられないときは、元のアーカイブは変わらない。ログの COPY は置き換えが終わってから出る。
- 中にすでに同じ名前があるときは、通常のフォルダーと同じ確認画面で、上書き・別名・スキップなどを選ぶ。大文字と小文字だけが違う名前も同じ名前として確認する。
- 7Z と TAR では、1回の追加の中で同じ名前を2回書くことはできない（その追加全体を取り消す）。
- LZH/LHA の編集では、触れていないファイルの更新日時はそのまま残る。
- フォルダーを追加したとき、中のファイルが全部入ったフォルダーだけマークを外す。スキップしたものがあるフォルダーはマークしたままにする。

## 大文字と小文字だけが違う名前

`README` と `readme` のように大文字と小文字だけが違うファイルは、アーカイブの中では別々に表示し、開く・取り出す・削除は選んだほうだけを対象にする。フォルダーは1つにまとめて表示する。Windows のフォルダーへ取り出すときは、同じ名前として確認画面が出る。
