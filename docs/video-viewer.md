# 動画ビューア

動画を Windows の再生機能で再生する。開くとすぐに再生を始め、画面に縦横比を保って表示する。
コーデックは同梱していないので、再生できる形式は Windows に入っているコーデック次第。拡張子を登録していても、その動画が必ず再生できるとは限らない。

## 開き方

ファイル一覧で、`[extensions]` セクションに `&videoviewer;` を割り当てた拡張子を Enter で開く。標準では次の拡張子を登録している。F3 でも動画ビューアで開く。

.mp4 / .m4v / .wmv / .avi / .mov / .mpg / .mpeg / .mkv / .webm

```ini
[extensions]
.mp4 ---- &videoviewer;
# 標準の割り当てを無効にする例
.webm ---- &none;

[keys.file]
# 拡張子にかかわらず動画として開くキーの例
>KEY_G -s-- &videoviewer;
```

アーカイブの中の動画は、一時フォルダーへ取り出してから再生する。大きな動画は取り出しに時間がかかり、一時フォルダーのドライブに空きが必要。

## 操作

| 操作 | キー | 命令 |
| :--- | :--- | :--- |
| 操作一覧の表示 | F1 | &help; |
| 再生・一時停止 | Space / F2 | &playpause; |
| 1秒戻る・進む | ← / → | &backward1; / &forward1; |
| 10秒戻る・進む | Shift+← / F3、Shift+→ / F4 | &backward; / &forward; |
| 音量を下げる・上げる（5ずつ） | ↓ / F5、↑ / F6 | &volumedown; / &volumeup; |
| 消音の切替 | M / F7 | &mute; |
| 停止して先頭へ | F8 | &stop; |
| 再生・一時停止の状態のまま先頭へ | Home / F9 | &beginning; |
| 閉じる | Enter / Esc / F12 | &close; |

- キーは `[keys.video]` セクションで変更できる（F1〜F12 と修飾キー付きも含む）。同じキーを2回書くと後の行が優先し、`&none;` でそのキーを無効にする。閉じるキーをすべて無効にしないこと。
- Shift+F1〜F12 は、初期状態では Shift なしと同じ命令。F10・F11 は割り当てなし。
- 下の位置バーをクリック・ドラッグしても移動できる。長さのわからない動画では使えない。

```ini
[keys.video]
>KEY_SPACE ---- &playpause;
>KEY_LEFT  -s-- &backward;
>KEY_F2    -s-- &stop;
>KEY_ESC   ---- &close;
```

## 再生について

- 音楽プレイヤーで再生中のときは、音楽を一時停止する。動画を閉じても音楽は自動では再開しない。
- 音量の初期値は `%masterVolume`。動画の中で変えた音量は、そのとき開いている動画にだけ効く。
- 最後まで再生すると止まる。再生操作で先頭から始まる。

## 再生できないとき

再生できない動画は、ビューアの中にエラーを表示する。ほかのアプリに切り替えて再生することはない。

- `0xC00D11B1` は「ファイルの再生を開始できなかった」という意味で、コーデック不足とは限らない。動画のコーデックと、Windows のメディア機能が入っているか（N エディションなど）を確かめる。
- 再生できない形式は、Microsoft Store の拡張機能（HEVC ビデオ拡張機能など）を入れると再生できることがある。
