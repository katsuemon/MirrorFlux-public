# VGM・S98 の対応状況

VGM・VGZ・S98 は、MirrorFlux の VGM エンジンで再生する。Yamaha の FM 音源は ymfm、それ以外の音源チップは個別にライセンスが明記された実装（`mf_chips.dll`）で鳴らす。
再生の操作と画面は [音楽プレイヤー](music-player.md) を参照。

## VGM

- VGM 1.00〜1.72 に対応する。VGZ（gzip 圧縮）も開ける。展開後のサイズが 256 MiB を超えるファイルは開かない。
- VGM の仕様にある 48 種類すべての音源チップを鳴らせる。同じチップ2基の構成にも対応する。
- 曲全体の命令を再生前に確認し、壊れた命令やループ位置の誤りがあるファイルは、理由を表示して再生しない。

対応する音源チップ:

SN76489 / T6W28、YM2413 / VRC7、YM2612 / YM3438、YM2151、SegaPCM、RF5C68 / RF5C164、YM2203、YM2608、YM2610 / YM2610B、YM3812、YM3526、Y8950、YMF262、YMF278B（OPL4）、YMF271、YMZ280B、PWM（32X）、AY-3-8910 / YM2149、Game Boy、NES APU / FDS、MultiPCM、uPD7759、MSM6258 / MSM6295、K051649（SCC）、K054539、HuC6280、C140 / C219、K053260、Pokey、QSound、SCSP、WonderSwan、VSU（バーチャルボーイ）、SAA1099、ES5503、ES5505 / ES5506、X1-010、C352、GA20、Mikey、K007232、K005289、MSM5205 / MSM6585、MSM5232、BSMT2000、ICS2115

## S98

S98 のバージョン 0〜3 に対応する。YM2608 のリズムや ADPCM も鳴る。

- 対応する音源: YM2149 / AY-3-8910、YM2203、YM2612、YM2608、YM2151、YM2413、YM3526、YM3812、YMF262、SN76489
- 種類の違う音源の組み合わせと、同じクロックの YM2203 2基には対応する。それ以外の同じ音源の複数構成と、圧縮された S98 は開かない。
- 曲名などのタグは CP932（Shift_JIS）と BOM 付き UTF-8 を読める。

## 外部データ（ROM）

- **YM2608 のリズム**: `YM2608_ADPCM.ROM`（8192 バイト）を `mf.exe` と同じフォルダーか、その下の `roms` フォルダーに置く。ないときはリズムの6音だけが鳴らない。
- **YMF278B（OPL4）**: PCM を使う曲は `yrw801.rom` を、曲・`mf.exe`・その `roms` フォルダーのいずれかに置く。ないときは ROM がないことを表示する。FM だけの曲は ROM なしで鳴る。

詳しくは [外部データの案内](external-data.txt) を参照。

## 画面の表示

- 鍵盤・レベルメーター・左右の出力は、音源ごとにチャンネル（声）を分けて表示する。例えば YM2608 は FM 6・PSG 3・ADPCM 1・リズム 6 の16行、YMF262 は 18行、ES5503 は 32行、ES5505 / ES5506 は 32行。
- 声ごとの情報を取り出せない音源は、チップ全体を1行の `MIX` として表示する。
- 表示は音源チップへの書き込みや再生状態から求めた目安で、音そのものには影響しない。

## 制限

- 実機と完全に同じ音を出すことは保証しない。VRC7 は ymfm の内蔵音色、YM2164 は YM2151 として鳴らす。音源の細かい型番の違いや、任意のアナログ出力の設定はすべては再現しない。
- 鳴らせるのは記録されたデータに含まれる音だけ。例えば、PCM の命令を含まない VGM では、元のゲームの PCM の音は鳴らない。
- VGM・S98 は再生位置の移動（シーク）に対応していない。

参考: [VGM の仕様](https://vgmrips.net/wiki/VGM_Specification)
