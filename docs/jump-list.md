# ジャンプリスト

`mf.ini` に登録した移動先（最大10件）を一覧から選んで、操作中のパネルをそのフォルダーへ移す。
フォルダーのほか、アーカイブとアーカイブの中のフォルダーにも移動できる。

## 開き方

ファイル一覧で **Shift+J** か **F10**（命令 `&jumplist;`）を押す。F10 の表示名は既定で「パス選択」（`%fn10`）。

## 画面

- 登録番号（01〜10）と移動先を、番号順に並べる。登録していない番号は表示しない。
- 表示名を指定した移動先は、その名前を表示する（[設定](#設定)）。
- デスクトップ・ダウンロード・マイドキュメント・ピクチャ・ミュージック・ビデオの各フォルダーは、パスの代わりにこの名前を表示する。その下のフォルダーや、同じ名前の普通のフォルダーはパスのまま。
- 移動先が見つからないときは、一覧の中にエラーを表示し、パネルは移動しない。

## 操作

| 操作 | キー |
| :--- | :--- |
| 選択 | ↑ / ↓ |
| 番号で選択（0 は10番） | 1〜9 / 0 |
| 選んだ移動先へ移動 | Enter / ダブルクリック |
| 閉じる（移動しない） | Esc |

- 開いた直後から選択行で操作できる。数字で選んだ後やエラーの後も、そのまま上下キーで続けられる。
- 移動先の確認とアーカイブの読み取りはバックグラウンドで行う。

## 設定

`mf.ini` の `%jumpPath01`〜`%jumpPath10` に登録する。変更はアプリの再起動で反映される。

```ini
# 初期の登録
%jumpPath01  shell:Desktop
%jumpPath02  shell:Downloads
%jumpPath03  shell:Personal
# 登録の例
%jumpPath04  C:\Work
%jumpPath05  "C:\My Documents","ドキュメント"
%jumpPath06  %USERPROFILE%\Music\VGM,"VGM"
%jumpPath10  .
```

- **表示名**: パスの後ろに `,"表示名"` を付けると、一覧にその名前を表示する。付けなければパス（既知のフォルダーはその名前）を表示する。
- **空白を含むパス**: `"` で囲んでもよい。
- **環境変数**: `%USERPROFILE%` などを使える。
- **相対パス**: `mf.exe` のフォルダーが基準。例の `.` は `mf.exe` のフォルダー。
- **Windows のフォルダー**: `shell:Desktop`（デスクトップ）・`shell:Downloads`（ダウンロード）・`shell:Personal`（マイドキュメント）・`shell:My Pictures`・`shell:My Music`・`shell:My Video` は、Windows に設定された実際の場所を指す。OneDrive や別のドライブへ移していても追従する。`%USERPROFILE%\Desktop`・`Downloads`・`Documents` と書いても同じ。
- 値を書かない行（例 `%jumpPath04`）は一覧に出さない。
