# 音楽プレイヤー

ゲーム音楽（チップチューン）と一般の音声ファイルを再生する。
ファイル一覧の隅に出る**サウンドバー**と、鍵盤・レベルメーター・レジスタを並べた全画面の**サウンドビューア**の2つがあり、同じ再生を共有する。サウンドビューアを閉じても再生はサウンドバーで続く。

## 対応形式

| 形式 | 拡張子 | 再生方法 |
| :--- | :--- | :--- |
| VGM・S98 | .vgm / .vgz / .s98 | MirrorFlux の VGM エンジン（ymfm と各音源チップの実装）。対応チップは [VGM の対応状況](vgm-compatibility.md) を参照 |
| NSF・HES・SPC・GBS ほか | .nsf / .nsfe / .hes / .spc / .gbs / .kss / .ay / .gym / .sap | Game_Music_Emu |
| MDX・PDX | .mdx（PDX は自動で読む） | MXDRV 互換のシーケンサー（MirrorFlux 独自の実装）と ymfm の YM2151 |
| 一般の音声 | .mp3 / .wav / .flac / .m4a / .wma / .aac | Windows の音声再生 |

一般の音声ファイルはサウンドバーだけで再生し、鍵盤の代わりにスペクトラムとシークバーを表示する。

## 開き方

ファイル一覧で、標準では次のように開く。

- **Enter**: サウンドバーで再生する。ファイル一覧の操作はそのまま続けられる。
- **Shift+Enter**: サウンドビューアで開いて再生する（チップチューン形式のみ）。

拡張子ごとの割り当ては `mf.ini` の `[extensions]` セクションで変えられる。アーカイブの中の曲は、その曲だけを一時フォルダーへ取り出して再生する。MDX は同じアーカイブの中の PDX も一緒に取り出す。

```ini
[extensions]
.vgm ---- &miniplayer;
.vgm -s-- &vgmplayer;
```

## サウンドバー

再生中だけ、ファイル一覧の隅に表示する。状態（PLAY / PAUSE）、経過時間と曲の長さ、曲名、16チャンネルの鍵盤・レベルメーター・左右の出力を表示する。NSF・NSFE・HES で1ファイルに複数の曲があるときは曲番号も表示する。
ボタンで一時停止・停止・曲番号の前後・サウンドビューアへの切替ができる。一般の音声ファイルはシークバーをクリックして再生位置を移動できる。

ファイル一覧にいるまま、次のキーで操作できる。`mf.ini` で同じキーに別の機能を割り当てている場合はそちらを優先する。

| キー | 操作 |
| :--- | :--- |
| Ctrl+P | 一時停止・再開 |
| Ctrl+S | 停止 |
| Ctrl+← / → | 5秒戻る・進む（シークできる曲のみ） |
| Ctrl+↑ / ↓ | NSF・NSFE・HES の前・次の曲番号 |
| Ctrl+M | サウンドビューアを開く |

## サウンドビューア

### 画面

- **鍵盤**: 12チャンネルを表示し、マウスホイールや Shift+PageUp / PageDown で他のチャンネルへスクロールする。各行の上にチャンネル番号と音源名（例 `CH 01 YM2151 FM`）、右端に音名とセントのずれ（例 `o4c+ +23¢`）を表示する。半音より細かい実際の音程の位置には縦棒を表示し、ビブラートやポルタメントで滑らかに動く。鍵盤の範囲（o0c〜o8b）より高い音・低い音は、その側の端の縦の真ん中に、キーONと同じ色（`%theme_MusicKeyLamp`）の三角を表示する。まだ使われていないチャンネルは暗く表示する。
- **レベルメーター・左右の出力**: チャンネルごとの音量の目安と左右のバランスを表示する。
- **スペクトラム**: 実際に出ている音から計算する。
- **レジスタ**: 音源チップに最後に書き込まれた値を16×16で表示する。F11 で表示するチップ・ポートを切り替える。
- **情報**: 曲名・ゲーム名・機種・作者・ファイルの種類・使っている音源、経過時間・曲の長さ・ループ回数・現在時刻を表示する。`FM CORE:` はソフトウェアで鳴らしている FM 音源、`EXT DEVICE:` は音を送っている NanoDrive を表す。MDX では使った PDX のパスを表示する。
- **アルバム画像**: 再生中の曲のフォルダーにある画像を右上に表示する。
- **曲の一覧**: 画面下部に、ファイル一覧で開いていたフォルダーのフォルダー・アーカイブ・曲を並べる。並び順はファイル一覧の設定に従う。曲を選んでも、今の再生はそのまま続く。
  - VGM・VGZ は、ファイル名の代わりに曲の中の曲名（GD3 タグ。日本語の曲名を優先）を表示する。T キーでファイル名の表示と切り替えられる。曲名のないファイルはファイル名を表示する。
  - MDX は、ファイル名の後ろに曲の中のタイトルを表示する。

### 操作

| 操作 | キー | Fキーの命令 |
| :--- | :--- | :--- |
| 操作一覧の表示 | F1 | &help; |
| 再生・一時停止 | Space / F2 | &playpause; |
| 選んだ曲を再生 | Enter / ダブルクリック | |
| 前の曲・次の曲 | F3 / F4 | &previous; / &next; |
| 連続再生（PLAY ALL）の切替 | F5 | &playall; |
| 1曲リピート（REPEAT）の切替 | F6 | &repeat; |
| シャッフル（SHUFFLE）の切替 | F7 | &shuffle; |
| 停止 | F8 | &stop; |
| ループ回数の切替（∞ → 1 → 2） | F9 | &loops; |
| 5秒早送り | F10 | &forward; |
| レジスタ表示の切替 | F11 | &registers; |
| 閉じる（再生はサウンドバーで続く） | F12 / Esc / Q | &close; |
| 曲の一覧の選択 | ↑ / ↓、PageUp / PageDown | |
| 親フォルダーへ | BackSpace / Alt+↑ | |
| VGM の曲名とファイル名の表示の切替 | T | &titles; |
| 曲番号の切替（複数曲のファイル） | ← / → | |
| 鍵盤のスクロール | Shift+PageUp / PageDown、マウスホイール | |
| チャンネルの消音 | 1〜8（左8列）、Shift+1〜8（右8列）、レベルメーターのクリック | |
| ドライブの選択 | L | |

- F1〜F12 と Shift+F1〜F12、曲名とファイル名の切替のキーは `[keys.music]` セクションで変更できる。ファンクションキーの表示名は `%mfn01`〜`%mfn12`。

```ini
[keys.music]
>KEY_T   ---- &titles;     # VGMの曲リストを曲名／ファイル名で切り替え
```
- 消音したチャンネルは、メーター・鍵盤・左右の表示が暗くなる。もう一度押すと戻る。曲を変えるかサウンドビューアを閉じると解除される。
- 早送り・巻き戻しとシークバーでの移動は、一般の音声ファイルだけで使える。VGM・S98・GME の各形式・MDX ではボタンが暗くなり、操作できない。
- サウンドビューアを閉じると、ファイル一覧は曲の一覧で開いていたフォルダーと選択位置に移る。

### 連続再生・ループ・フェード

- ループ回数を 1 か 2 にすると、その回数ループしたところから10秒かけて音量を下げ、1秒あけて次の曲へ進む（REPEAT のときは同じ曲を最初から）。∞ のときは止まらずにループし続ける。
- PLAY ALL を入れたとき、ループ回数が ∞ なら 2 に切り替える。ループしない曲は、PLAY ALL またはループ回数を指定していれば、曲の終わりから1秒あけて次へ進む。
- 一時停止するとフェードも止まる。曲を手で選ぶと通常の音量ですぐ始まり、停止すると予定していた曲送りを取り消す。

## 設定

`mf.ini` の `[GME]` セクションで設定する。変更はアプリの再起動で反映される。

```ini
[GME]
# 再生音量 0〜100（既定 50）。Windows の音量や NanoDrive の出力には影響しない
%masterVolume  50
# MDX の PDX を探す追加のフォルダー（; 区切り。相対パスは mf.exe のフォルダーが基準）
%pdxSearchPaths samples;D:\Music\PDX
# NanoDrive 6/7/8 への実機出力（true / false）
%ND6-NDSIF  false
%ND7-NDSIF  false
%ND8-NDSIF  false
```

- 画面の各色は `%theme_Music...` の行で変更できる。
- サウンドビューアのキーは `[keys.music]` セクションで設定する。

## MDX と PDX

PDX は MDX と同じフォルダーを最初に探し、見つからなければ `%pdxSearchPaths` のフォルダーを左から順に探す。拡張子のない名前は `.pdx` を付けても探す。PDX が見つからないときは FM だけで再生し、`PDX: MISSING <名前> (FM ONLY)` と表示する。Z-MUSIC には対応していない。

MDX のコマンドは MXDRV 2.06+16/+17 の動作に合わせている（参考: [MXDRV データ資料](https://w.atwiki.jp/mxdrv/pages/23.html)）。次は再現しない。

- 拡張コマンドのうち、他のチャンネルを操作する `$E7 $04` と、PCM8 を直接駆動する `$E7 $02`（引数は読み飛ばして演奏を続ける）。
- MXDRV 2.06+16/02EX だけの `$E6`（相対ディチューン・移調）。他の未定義のコマンドと同じく、そのトラックの演奏を終える。

## 外部データ（ROM）

ROM・波形・楽曲データは同梱していない。必要な場合は、ご自身で用意したものを置く。

- **YM2608（OPNA）のリズム音**: 8192 バイトの `YM2608_ADPCM.ROM` を `mf.exe` と同じフォルダーか、その下の `roms` フォルダーに置く。ないときはリズムの6音だけが鳴らず、FM・SSG・ADPCM は鳴る。
- **YMF278B（OPL4）**: PCM を使う曲は `yrw801.rom` を、曲・`mf.exe`・その `roms` フォルダーのいずれかに置く。FM だけの曲は ROM なしで鳴る。

詳しくは [外部データの案内](external-data.txt) を参照。

## NanoDrive（NDSIF）への実機出力

`%ND6-NDSIF`・`%ND7-NDSIF`・`%ND8-NDSIF` を true にすると、VGM・VGZ・S98 の対応する音源チップを NanoDrive に送って鳴らす。ND8 では MDX も鳴らせる。NanoDrive に送った音はPCでは鳴らさない。

| NanoDrive | 送る音源 |
| :--- | :--- |
| ND6 | SN76489、YM2612 |
| ND7 | YM2413（OPLL）、YM2203、YM3812、YM3526、YMF262、AY-3-8910 |
| ND8 | YM2151、OKIM6258（PCM）。MDX は FM を YM2151 に、PDX の PCM8 の音を1本に混ぜて OKIM6258 に送る |

- ND6・ND7・ND8 はそれぞれ別々の COM ポートで、同時に使える。Bluetooth のシリアルポートは検出の対象にしない。
- NanoDrive が要求したクロックに対応していないチップや、VRC7 などはソフトウェアで鳴らす。
- 再生中に NanoDrive との接続が切れても、アプリは終了しない。次の曲から検出し直す。
- MDX の PCM8 は最大8音を1本に混ぜて送るため、左右の振り分けはなくなる。NanoDrive が OKIM6258 のストリームに対応していないときは FM だけを NanoDrive で鳴らし、PCM8 はPCで鳴らす。
- Windows に音声出力デバイスがないときでも、曲の音を NanoDrive に送れる場合は、NanoDrive だけで再生する。送れる音がない曲や、VGM・S98・MDX 以外の形式は「音声出力デバイスがありません」と表示して再生しない。

## 表示についての注意

- 鍵盤とレベルメーターは、音源チップへの書き込みや音声から求めた**目安**で、各声の実際の音を個別に測ったものではない。
- NSF などの Game_Music_Emu の形式は、各声の音から音程を推定する。推定した音程には `~` を付ける。打楽器や雑音など音程の決まらない音は、決まった鍵を光らせる。
- PCM の鍵盤の位置は再生速度からの目安で、録音された音そのものの音程ではない。
- 詳しいチップの対応と制限は [VGM の対応状況](vgm-compatibility.md)、レベルメーターの計算は [レベルメーター](level-meter.md) を参照。
